# Keybindings

|------------------|--------------------------------------|

| SUPER + SHIFT + Q| Exit Hyprland                        |
| SUPER + SHIFT + L| Lock and suspend                     |
| SUPER + G        | Toggle hypridle                      |
| SUPER + SHIFT + S| Screenshot to clipboard             |

| SUPER + 4        | Switch to workspace 4                |

| SUPER + SHIFT + Left  | Move window left                 |
